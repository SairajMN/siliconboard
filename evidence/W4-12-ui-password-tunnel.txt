W4-12 — UI password gate + public https hosting
Date: 2026-10-03
Commit: 3f63b51 (gate, tunnel unit, deploy wiring), docs follow-up

WHAT
  ui/server.py gains SB_UI_PASSWORD: POST /api/login, hmac.compare_digest,
  5 strikes -> 60s lockout (self-resetting), in-memory session delivered as
  HttpOnly; SameSite=Strict; Max-Age=43200 cookie. With a password set the
  token is REFUSED (no back door). /api/auth is the only public endpoint
  (mode + session? and nothing else).
  Frontend: prompt speaks both languages, chosen from the server; Enter
  submits; password never stored, never in a URL.
  Hosting: deploy/cloudflared.service = OUTBOUND Cloudflare quick tunnel to
  127.0.0.1:8080 (systemd unit siliconboard-tunnel, Restart=always).
  deploy.sh: UI_PASSWORD upsert (passed on stdin, not argv), tunnel install,
  /api/auth edge health check.

LOCAL GATE (server on 127.0.0.1:8103, SB_UI_PASSWORD set)
  banner                          "siliconboard ui on http://127.0.0.1:8103/ (password required)"
  GET  /api/auth                  {"mode": "password", "session": false}
  POST /api/login wrong           401 {"error": "wrong password (3 tries left)"}
  strikes 4..6                    401 401 429 429
  right password while locked     429 {"error": "too many attempts; wait 60 seconds"}
  right password after lock       200, Set-Cookie: sb_session=...; Path=/; HttpOnly; SameSite=Strict; Max-Age=43200
  GET  /api/runs + cookie         200
  GET  /api/runs ?t=<old token>   401   <- the token is not a back door
  GET  /api/runs (no creds)       401
  cookie file line                #HttpOnly_127.0.0.1 ... sb_session ...

PUBLIC (https://experiencing-occupied-sea-footage.trycloudflare.com)
