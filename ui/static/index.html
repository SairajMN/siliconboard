    How siliconboard works

    1. Write a plain-English block description and press Run.
    2. Watch each agent go: spec, RTL, lint, testbench, simulate, debug, synthesise, timing, report.
    3. Read the output — report, Verilog, waveform, and the raw tool evidence.

    The models propose, the tools decide. A pass comes from a Verilator log, a cell count from Yosys, a slack from OpenSTA — never from the model's word.
